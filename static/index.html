模型与密钥

密钥仅在本机浏览器保存（localStorage），用于调用阿里云 DashScope，提交时随请求发送。

该密钥同时用于两处：① 视频无字幕时的语音转写；② AI 字幕纠错与条理梳理。 若只处理「本身带有可提取字幕」的视频，留空也能跑通（基础规则清洗）。 模型选择在「🚀 新建解析」页的下拉框中设定（语音识别 / 文本 / 替代模型）。
B站登录 Cookie（可选，非必填）
不填也能用：没有字幕时应用会自动语音转写，无需任何 Cookie。 仅当你想优先提取「需登录才能看」的 UP 主字幕时才填它——获取方式：电脑浏览器登录 bilibili.com → F12 打开开发者工具 → 网络/Network 或 应用/Application → 复制请求头里的 Cookie 值（关键是含 SESSDATA）。
